# Architecture

The browser app and the Python tools use the same gap-colour projection approach. The sample debugging workflow is shown below.

```
┌───────────────┐    ┌──────────────────┐
│   print JPG   │    │ test/sample.jpeg │
│ (user upload) │    │                  │
└───────────────┘    └──────────────────┘
        │                      │
        └┐                   ┌─┘
         ▼ file input        ▼ argv
  ┌────────────┐    ┌────────────────┐
  │ index.html │    │ test/detect.py │
  └────────────┘    └────────────────┘
         │                   │
         │                   └┐
         ▼ sets/exports       ▼ overlay/sheet
 ┌──────────────┐    ┌────────────────┐
 │   browser    │    │ test/out/*.png │
 │ localStorage │    │                │
 └──────────────┘    └────────────────┘
```

## The boxes

**index.html** — the whole app. Hash router with four views (`/sets`, `/upload`, `/set/:id`, `/exports`), upload+auto-slice flow, tierlist drag/drop editor and PNG exporter. The grid detector lives in `detectGrid` + `findGridLines` (gap-colour mask, projection threshold, run centres); UI-icon filter in `isUiIcon`.

**cli/inventory_grid.py** — shared Python grid detection, card extraction, and contact sheet rendering. Includes the projection detector and the full-screen locker layout detector.

**cli/import_inventory.py** — batch CLI. Reads screenshots from a directory and writes card PNGs, a combined contact sheet, and a source manifest.

**test/detect.py** — diagnostic entry point that runs the projection detector against `sample.jpeg` by default. Writes the grid overlay, contact sheet, and X/Y projections.

**browser localStorage** — client-only persistence. Two keys: `sets` (cards + per-set tier list + layout + cover index) and `exports` (generated tierlist PNGs).

**test/out/\*.png** — example images tracked in the repository and regenerated by the detector harness. Git ignores newly generated files in this directory.

The browser and Python implementations are independent so the web app can still run as a standalone HTML file.
